- tools/weapons/vox.py: восстановлена отсутствовавшая to_blender для сохранения .blend.

- compare_weapon_stage.py: совпадение OBJ геометрии, mesh/glow конфигов и glow-цветов;
  сборка итоговых сравнительных листов.
- preserve_weapon_stage.py: 32 кадра скопированы из временных каталогов в проект;
  оба экспортированных конфига совпадают с src.
- check_weapon_contracts.lua: 32 сборки в Edit, существующие меши + новый фолбэк;
  Root/Grip/BladeBase/BladeTip и числовые BladeLength/Extent/CenterY присутствуют.
- node tools/sync.js: синхронизировано 311 Lua-файлов из текущего src, включая
  уже существовавшие пользовательские изменения (их исходники не переписывались).

не меняя файлы. Автоматическая проверка контрактов и визуальный осмотр листов
выполнены основным Kin.
