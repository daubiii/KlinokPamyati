## Стиль-гайд (обязателен для любого редизайна)
- Бумажная система «Humble Gift» (`Lib/PaperUi.lua`): пергамент #ECDEC0,
  чернила #423020, красный #96342C (P.red), золото #FFCC54, эхо-бирюза #78E8FF.
- Пиксельный шрифт Arcade (всё, что видит игрок — этим шрифтом).
- Окна = пергаментные листы со стопкой (PaperUi.sheet), лента-заголовок,
  кнопки PaperUi.button с нажатием. Темные сцены — PixelUi (тёмные панели,
  золотая рамка).

## Известные слабые места (по решениям владельца)
- **Иконки предметов/валют** (20×20 атлас) — простоваты: перерисовка по
  промтам `docs/АРТ_ЗАДАНИЕ.md` §4 (лист 64×64 → я уменьшу до 20 и соберу
  атлас на старых координатах).
- **Выбор пути** — плоские пергаменты: планируются GPT-портреты классов
  (§3.3) в артовые окна карточек.
- **Справка слайд 1** — кей-арт придумывает владелец (остальные 6 слайдов
  с иллюстрациями из `Промт 3.2` — готовы, не подключены: ждут решения
  владельца).
- **Круглые медальки** в выборе пути убраны (v4): иконки оружия/брони без
  кругов, с тенью.
