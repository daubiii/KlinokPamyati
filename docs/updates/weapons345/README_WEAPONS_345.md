# Оружие этажей 3–5: модели, способности, эффекты, звуки, иконки

Охота (этаж 3, 7 видов оружия), Горн (этаж 4, 9), Летопись (этаж 5, 9). 16 способностей,
у каждой: серверная логика, клиентский эффект, анимация героя, звуки и иконка.
В архиве только новые и изменённые файлы — разложить поверх проекта с теми же путями.

## Установка (по порядку)

1. **Код.** Скопировать `src/` поверх проекта, синхронизировать через Rojo.
2. **Меши.** Studio, режим Edit: File → Import 3D → `tools/weapons/weapons_floor3.glb`, `…floor4.glb`,
   `…floor5.glb` (настройки по умолчанию). Затем в Command Bar — содержимое
   `tools/weapons/AssembleWeaponsFloors345.lua`, и Ctrl+S.
   Без этого шага оружие строится из вокселей по `WeaponMeshDataFloor3/4/5`: играть можно, просто менее гладко.
3. **Витрина (проверка на глаз).** `tools/weapons/PreviewWeaponsFloors345.lua` в Command Bar выставит всё оружие
   тремя рядами перед камерой (в Output у каждого: «меш» или «воксели»). Повторный запуск убирает витрину.
4. **Эффекты (по желанию).** Сервер сам достраивает шаблоны FX при старте. Чтобы видеть и править их в Explorer —
   `tools/fx/BuildFxWeapons345.lua` в Command Bar.
5. **Свои текстуры эффектов.** Загрузить 12 PNG из `tools/fx/textures_345/` (Asset Manager → Bulk Import),
   вписать id в `Shared/Fx/FxWeapons345.lua` → `S.NEW`, затем BuildFxWeapons345 с `REBUILD = true`.
   Пока id пустые, берутся существующие текстуры проекта (`S.FALLBACK`) — эффекты работают и без загрузки.
6. **Иконки способностей.** Загрузить `assets/abilities345_atlas.png` (90×90, 16 иконок 20×20), вписать id в
   `Shared/Config/AbilityIcons345.lua` → `atlas`. До этого HUD показывает похожие иконки из основного атласа
   (кинжал, молот, свиток, замок…). Перерисовать: `python3 tools/icons/icons345.py`.

```lua
print(game.ServerStorage.KlinokDebug.Cmd:Invoke("give floor3"))   -- всё оружие этажа, в руке первое
```

- этаж 4: cast quench apprentice crucible searing anvil heart slag unfinished;
- этаж 5: paper tome bookmark quill seal hourglass ink oblivion memory.

## Обновление 2: модели, ауры, присутствие, способности

**Переименования (этаж 3).** Копий больше нет: `boar_spear` → `hunt_broadsword` «Охотничий палаш» (редкий, обычный
меч), `royal_spear` → `royal_scythe` «Коса Королевского ловчего» (легендарка, серия ударов кос). Если у тестовых
профилей в DataStore остались старые id — выдайте оружие заново (`give broad`, `give royal`).

**Модели.** Переделаны все легендарки и секретки (royal_scythe, falconer_saber, anvil_hammer, forge_heart_blade,
slag_scythe, unfinished_blade, hourglass_maul, ink_blade, oblivion_scythe, memory_blade). Парящие неоновые
«точки» вокруг моделей убраны у всего оружия (экспорт удаляет несвязные островки вокселей). Листы —
`preview/weapons_floor3_v2.png`, `…4_v2`, `…5_v2`. **Меши нужно импортировать заново** (шаг 2 установки):
AssembleWeaponsFloors345 сам заменит старые `W_*`/`G*_*` в `ReplicatedStorage.WeaponMeshes`.

**Ауры.** У мешей есть `aura` — габарит клинка. VoxelWeaponBuilder ставит туда невидимую деталь `AuraVolume`,
и частицы ауры (FX.Weapon.<id>) идут по всему клинку, а не из одной точки. Легендарки и секретки — слои:
густые частицы по клинку, мерцание поверхности, шлейф частиц в мире за бегущим героем, мягкое свечение,
яркий свет (12–15 стадов). Аура строится на сервере, поэтому её видят все игроки.
Шаблоны аур помечены `version`: старые копии в месте пересоберутся сами при старте сервера.

**Присутствие (клиент, `Controllers/WeaponPresence`).** У всех игроков с легендаркой/секреткой в руке:
вспышка ауры раз в ~3 с (секретка ~2 с), пульс света и кольцо-волна у ног; у секретки ещё постоянный
вращающийся круг рун с искрами под ногами. Шаблоны — `FX/Presence/Ring|Sigil|Pillar` (белые, перекрашиваются в
цвет оружия).

**Находка.** Легендарка/секретка из сундука: всем игрокам — звук (`legendDrop` / `secretDrop`), столб света над
сундуком на 5–7 с, а остальным ещё баннер «Легендарное/Секретное оружие! <Игрок> достаёт «…»».

## Звуки

Описаны в `Shared/Config/SfxWeapons345.lua` (Sfx.lua подмешивает их сам). Только лицензированные источники:
Pro Sound Effects, APM, встроенные звуки движка. Для 7 ключевых звуков есть по 2–3 варианта:
huntPackHowl, huntHorn, forgeAnvilImpact, forgeBreath, chronDomeStart, chronTick, chronRecall.
Прослушать: `sfx huntHorn 2`; понравившийся номер записать в `picked` того же файла.
Рога у PSE нет — собран из низкого синт-гула, баса и удара APM: послушайте его в первую очередь.

## Что проверено, а что нет

- Проверено: все Luau-файлы компилируются, статический анализ новых файлов — без синтаксических ошибок и неизвестных переменных, автопроверка выше,
  модели — рендером листов превью (`sheet_iso`).
- **Не проверено в Studio** (нет доступа к Roblox): как выглядят ауры, вспышки, круг рун, столб света, эффекты и анимации в движении, громкость и
  тайминг звуков, баланс урона и перезарядок. Это стоит посмотреть первым делом командами выше.
- id звуков PSE подобраны по названиям в каталоге и не прослушаны: если какой-то не грузится или звучит не
  так — замените id в SfxWeapons345, код трогать не нужно.
