# Интерфейсы «студийного» уровня — что изменено

Коротко: у всех окон появились режиссура (перелистывание, каскады, толчки, печати,
покачивания) и сведённые звуки. Разговор с жителями — новое окно `DialogueWindow`,
Кузня Эха — полностью новый `ForgeWindow` на бумажном стиле Книги героя.

## Общие модули
| Модуль | Что делает |
|---|---|
| `Lib/UiMotion.lua` (новый) | `pageOut/pageIn` (листание), `cascade` (каскадное появление), `fadeIn/fadeOut` (прозрачность целой ветки), `punch`, `popIn`, `bob`, `breathe`, `hover`, `typewriter` (печать с паузами на знаках и «голосом»). |
| `Lib/UiSound.lua` | `UiSound.Mix` — многослойные звуки из лицензированных PSE/APM и звуков движка. `UiSound.blip(voice)` — слог «голоса». |
| `Lib/WindowBase.lua` | Окна с доской-заголовком (`title`) получили «вход»: звук, проявление виньетки, подъезд холста масштабом, всплытие крестика; при закрытии — звук и гашение. Отключить: `intro = false`. |
| `Lib/PixelUi.lua` | Кнопки — толчок при нажатии; крестик крутится при наведении; облачко реплики печатает с паузами и «голосом» (`bubble.voice = {pitch, volume}` или `false`). |

## Звуки (`UiSound.Mix`)
Книга/бумага: `page_turn`, `page_back`, `paper_slide`, `tab_select`, `stamp`.
Разговор: `dialog_open`, `dialog_close`, `dialog_next`, `talk_blip`, `choice_hover`, `choice_pick`, `new_topic`.
Кузня: `forge_heat`, `forge_anvil`, `forge_spark`, `forge_reveal`, `forge_quench`, `echo_socket`, `star_on`.
Прочее: `list_tick`, `confirm`, `stone_slab`, `stone_tick`, `medal`, `candle`, `gate_rumble`, `floor_pick`, `coin_tick`.

**Как заменить на свой звук:** добавьте в `Config/UiAssets.lua → Sounds` запись с тем же
именем и реальным id (`{ id = "rbxassetid://…", volume = 0.5 }`). Если id есть — играет он,
иначе — слои из Mix. Ничего в окнах менять не нужно.

## Окна
- **Книга героя (CharacterWindow)** — вкладки теперь перелистываются: старая страница уходит,
  новая въезжает с нужной стороны (вперёд/назад по порядку вкладок), закладка «толкается»,
  лента-заголовок гаснет и проявляется, звук страницы + шелест.
- **Разговор (DialogueWindow, новое)** — кинорамка, камера из-за плеча на жителя, лист с
  живым портретом (ViewportFrame с клоном модели), лента имени, печать текста голосом жителя,
  страницы, ответы-полоски справа (1–6), новые темы с красной точкой, темы-станции открывают
  окно (кузня, доска, лавка, стена, врата). Тексты/темы/голоса — `Config/HubDialogue.lua`.
  Выключатель: `Config/Hub.lua → Hub.TalkWindow` (`false` — старая строка внизу).
  Управление: E / Пробел / Enter / ButtonA — дальше, 1–6 — ответ.
- **Кузня Эха (ForgeWindow, новое)** — Оружейная слева, режимы Вплавить / Душа / Плавка
  (1–3), карточка с «Сейчас › После», ковка в 3 удара с раскалением и искрами, экран итога
  со звёздами по одной, двойное подтверждение плавки. W/S — клинок, Пробел — действие.
- **Доска заданий** — записки наклоняются под курсором, выбор не «перестраивает» список,
  лист задания проступает построчно, печать прихлопывается; сдача — штамп + толчок.
- **Лавка** — ценники качаются на верёвочках и при наведении, «КУПЛЕНО» штампом,
  Ивга говорит своим голосом, при нехватке — ценник дёргается.
- **Стена имён (топы)** — таблички высекаются снизу вверх, тройка — последней с медалью
  и зажжением свечи, числа набегают, смена вкладки — каменный звук и уход старых табличек.
- **Врата Печатей** — миры въезжают по очереди, подсветка выбранной печати дышит,
  выбор сложности со звуком/толчком, замок вздрагивает, «ВОЙТИ» дышит и гудит.
- **Сундук дня** — дни выкладываются по очереди, сегодняшний и 7-й покачиваются,
  «ОТКРЫТЬ» зовёт, перед открытием крышка дребезжит, награды вылетают из сундука,
  печать дня прихлопывается.

## Проверить в Studio
1. Книга: листание вперёд/назад, нет «залипших» страниц при быстром клике по вкладкам.
2. Разговор: портрет в ViewportFrame (модель жителя видна), камера не уходит в стену.
3. Кузня: скролл Оружейной (`CanvasPosition`) следует за выбором W/S; ковка/плавка.
4. Громкость звуков Mix под свою музыку (множители в `UiSound.Mix`).
