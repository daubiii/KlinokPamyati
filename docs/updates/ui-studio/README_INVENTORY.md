# Книга героя — инвентарь и интерфейс персонажа (03.11.2026)

Полный инвентарь персонажа на арте **Humble Gift — Paper UI System v1.1**.
Одно окно-книга с тремя закладками на деревянном столе:

| Закладка | Клавиша | Что внутри |
|---|---|---|
| Снаряжение | I / Tab | сумка по 8 категориям, кукла с 6 слотами + быстрый предмет, карточка предмета с действиями, «Сила» |
| Герой | C | класс, уровень и опыт, 12 характеристик с пояснениями, летопись (враги, боссы, сундуки…), 3 класса |
| Журнал | J | сюжетные и выполненные задания (заказчик, цитата, шаги, награды, «Взять задание»), архив фрагментов |

Та же клавиша закрывает книгу, другая — листает на свою закладку.
**G** — быстрый предмет (слот справа от панели способностей на HUD).

## Что добавлено

**Сервер**
- `Systems/InventoryService.lua` — сумка (стопки до 99), быстрый предмет, аксессуары
  (амулет + кольцо, статы здоровье/броня/урон), использование с откатами групп
  (зелья 6 с, еда 3 с), баффы (броня, урон, реген), разбор аксессуаров в пыль эха,
  выпадение припасов и аксессуаров из сундуков, данные для книги (`GetCharacter`).
  Поля профиля создаются лениво — старые сохранения получают стартовый мешок
  (3 лечебных отвара, 2 хлеба) и работают без миграции.
- `LootService` — сундук после оружия и брони катит припасы (1–2 стопки, у босса 2–3)
  и аксессуар (8 %, у босса 40 %, редкость растёт с этажом); свечение сундука —
  по лучшей находке.
- `MeleeService` / `CombatService.hooks.damageBonus` — бонус урона аксессуаров и баффа.
  Здоровье и броня аксессуаров — через тот же хук `gearStats`, что у брони.
- `DebugCommands` — `item <id|all> [n]`, `acc <id|all>`.

**Конфиги**
- `Config/Items.lua` — категории, 14 предметов сумки, 8 аксессуаров, таблица сундука,
  стартовый мешок. Только числа и подписи.
- `Config/PaperAtlas.lua` — координаты 167 кусков атласа (генерируется).
- `Config/Binds.lua` — Hero = C, Journal = J, UseItem = G.
- `Config/UiAssets.lua` — `PaperAtlas`, `PaperDesk` (id картинок, см. ниже).

**Клиент**
- `Lib/PaperUi.lua` — бумажные кирпичики: лист со стопкой, стол, лента, кнопка с
  нажатием, полоска-строка, слот с рамкой выделения, полоса опыта/здоровья,
  печать-штамп (20 кадров), появление листа.
- `Windows/CharacterWindow.lua` — сама книга. Старое окно сохранено как
  `InventoryWindow` (станция `InventoryClassic`).
- `Controllers/QuickItemController.lua` — быстрый слот на HUD (иконка, количество,
  откат, клавиша) и бумажные листки «+2 Хлеб» справа при находках.
- `Controllers/StationController.lua`, `Lib/StationApi.lua` — закладки, клавиши, API `character`.

**Инструменты и проверки**
- `tools/paperui/build_paper_atlas.py` — собирает атлас из папки набора.
- `tools/lua/test_items.lua` — 23 проверки конфига и атласа
  (`LUAU=путь/к/luau node tools/run-luau.js tools/lua/test_items.lua`).

## Загрузка арта в Roblox (один раз)

1. Studio → Asset Manager → Bulk Import: `assets/paper/paper_ui.png` и `assets/paper/paper_desk.png`.
2. Скопировать id и вписать в `src/ReplicatedStorage/Shared/Config/UiAssets.lua`:
   ```lua
   PaperAtlas = "rbxassetid://<id paper_ui.png>",
   PaperDesk = "rbxassetid://<id paper_desk.png>",
   ```
3. Пока id пустые, книга рисуется заглушками (бумажный цвет + иконки атласа v2) —
   всё кликается и работает, только без арта.

Пересобрать атлас (если поменяется набор):
```
python3 tools/paperui/build_paper_atlas.py "<папка Humble Gift - Paper UI System v1.1>"
```
Скрипт перезапишет `assets/paper/*.png` и `Config/PaperAtlas.lua` — id в Roblox
придётся загрузить заново.

## Проверка в Studio

- `item all 3` — по 3 каждого предмета сумки; `acc all` — все аксессуары.
- I → «Снаряжение»: выбрать аксессуар → «Надеть», «Сила» и здоровье растут; разбор —
  двойным нажатием («Точно? +N пыли»).
- Припас → «В быстрый слот», закрыть книгу, G на HUD → лечение, затемнение отката.
- C → «Герой», J → «Журнал».
