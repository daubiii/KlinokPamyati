## Известные особенности

* **Полоски здоровья сделаны геометрией.** `BillboardGui` и динамически созданный
  `ScreenGui` над врагами в этой среде не отрисовываются (проверено тестовыми
  плашками), части рендерятся. Минус: масштабируются с расстоянием и перекрываются
  стенами.
* **Сохранение профиля в Studio — в памяти сессии.** DataStore требует
  `Enable Studio Access to API Services` в настройках места. Код готов: сам
  переключается, когда DataStore доступен.
* **Камера написана своя:** в сборке Studio 0.743 нет `PlayerModule`, штатный
  shift lock включить нечем.
* **Прыжок на пробеле**, рывок на Q / Shift (решение владельца, 21.10.2026).
* Урон/сложность не балансировались: числа из приложения Б, живучесть не
  настраивалась. Контрольная точка плана (недели 6–8) — за плейтестом.
