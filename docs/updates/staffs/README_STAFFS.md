# Посохи: разбор, переделка, баланс (08.11.2026)

Ставится поверх KlinokWeaponsV2.zip (в архиве только изменённые и новые файлы).

## Что нашёл при разборе 19 заклинаний
Сервер и клиент заклинаний в целом написаны целиком: я сверил все 63 фазы, и у каждой есть
обработчик эффекта. Не работали они из-за подключения, которое потерялось при наложении
пакетов (вернул ещё в V2). Сейчас нашёл ещё три поломки и одну дыру в балансе:

1. **Посох Королевского ловчего.** У его заклинания то же имя (`last_hunt`), что у Косы ловчего.
   Коса затирала заклинание, и маг делал рывок косой воина без маны. Теперь у посоха своё
   заклинание — «Королевская ловля» (ниже).
2. **Пассивка «Угли» на Расплавленном скипетре.** Та же история с Клинком горна (`embers`):
   в подсказке висел текст воина, а взрыв горящих при смерти падал с ошибкой — не работал.
   Новое имя пассивки — `cinders` («Тлеющие угли»), механика прежняя.
3. **Иконки.** У всех 19 заклинаний были общие значки интерфейса, у некоторых по два одинаковых.
   Нарисовал свой пиксельный атлас — см. `mage_spells_preview.png`.
4. **Баланс.** Обычные удары мага по толпе отставали от воина на 25–40%. Воин дугой задевает
   2 из 4 врагов, снаряд — одного. На большинстве этажей маг проигрывал на 15–28% (таблица ниже).

## Переделано
- **Королевская ловля** (huntmaster_staff, легенд., этаж 3; 45 маны, 16 с). Сеть летит навесом
  на 10 стадов и накрывает R6: 60% урона, держит 2 с (боссов 0,6 с) и подтягивает к центру.
  Пойманные подсвечены, над ними красная метка. Дальше 3 золотых копья падают с неба в самых
  живучих: 140% в R2,5, место удара видно за долю секунды. В конце сеть рвётся: 80%,
  замедление и отброс.
- **Призрачная стая** (pack_staff, эпик, этаж 3). 4 призрачных волка бегут к цели и кружат вокруг
  неё. Вой: соседи в R7 получают 80% и бегут в страхе 1,5 с, цель прижата 1 с. Потом волки по
  очереди кусают 6 раз по 55% и вместе прыгают на цель: 180% и замедление. Если цель умерла,
  стая переходит на ближайшего врага. Отличие от Своры воина: одна цель плюс разгон толпы.
- **Грибница** (spore_staff, эпик, этаж 2). 5 спор навесом засевают поляну R7 (её видно сразу):
  35% и яд. Через 1 с поляна 3 с выдыхает ядовитое облако — 25% каждые 0,5 с, яд, замедление 25%,
  грибы «дышат». В конце грибы лопаются: 80%.
- **Остановка времени** (clock_staff, эпик, этаж 5). Заморозка как была; добавлены две вещи.
  Пока враги стоят, минутная стрелка дважды обходит круг и режет всех по 55%, удар стрелок —
  220%. Потом стрелки идут назад: маг возвращает 25% здоровья, потерянного за последние 5 с
  (над ним цифра «+N»). Этим заклинание теперь отличается от «Печати» воина.

У всех четырёх — стандарт V2: зона на полу в размер серверной, хит-стоп на главном ударе,
тряска и свой звук на каждый такт (14 новых звуков `m*` из той же библиотеки, что у мечей).

## Баланс: маг против воина
Офлайн-калькулятор `tools/lua/balance_classes.lua` берёт числа из настоящих конфигов
и считает урон за 30 с боя: обычные удары плюс способность с перезарядкой, у мага ещё мана.
Есть два случая: одна цель и толпа из 4; итог — среднее двух. Уровень героя на этажах:
4/10/16/22/28.

| Этаж, редкость | Было | Стало |
|---|---|---|
| 1 обычные / редкие / эпики | −28% / −26% / −12% | −7% / −3% / −2% |
| 1 легендарка | +7% | +20% * |
| 2 обычные / редкие / эпики / легенд. | −22% / −10% / −27% / −20% | −4% / −1% / −7% / −1% |
| 3 обычные / редкие / эпики / легенд. | −18% / −9% / −18% / −15% | +1% / −5% / −5% / +1% |
| 4 обычные / редкие / эпики / легенд. / секрет | −22% / −9% / 0% / −9% / +3% | +2% / −2% / +1% / −3% / +3% |
| 5 обычные / редкие / эпики / легенд. / секрет | −22% / −27% / −18% / +3% / −14% | +2% / −10% / −4% / +1% / −6% |

\* Ключ Привратника слабее эпиков своего же этажа (−15% к ним). Маг-легендарка на 5% сильнее
маг-эпиков, как и положено. Ключ ты просил не трогать, поэтому скажи, если поднять ему урон.

Как добивался:
- **Финал серии посоха всегда взрывается**: R3, 75% урона соседям (`LootMage.FinisherSplash`).
  Это и «тяжёлый финал», и маг по толпе.
- **Урон 25 посохов** поправлен в пределах ±15%. Посохи с веером были слабее, с цепью и
  расколом — сильнее. Обычный или редкий посох не выше легендарок своего этажа.
- **Числа 10 заклинаний**:
  - выше: Цветение лотоса, Сад шипов, Сердце горна, Раскрытая книга, Вспомнить всё;
  - ниже: Врата света, Кованая молния, Чёрная клякса;
  - ещё два — Стая и Остановка времени — в составе переделки.

  Описания переписаны под новые числа. Пересчитать — одной командой (ниже).

Чего нет в расчёте (одинаково для обоих классов): таланты, пассивки легендарок, броня и души.
Воин переживает больше (броня, парирование), маг бьёт с дистанции — урон при этом равный.

## Установка
1. Скопировать `src/`, `tools/`, `docs/` из архива поверх проекта с заменой. Rojo → Connect.
   Новые модули: `Controllers/MageSpellFxV2`, `Config/AbilityIconsMage`.
2. **Иконки (по желанию):** загрузить `tools/icons/mage_spells_atlas.png` как картинку интерфейса
   и прислать мне id или вписать в `Config/AbilityIconsMage.lua` → `atlas = "rbxassetid://…"`.
   Пока id пустой, видны прежние значки — ничего не ломается.

## Проверка в Studio (Play, Command Bar, сервер)
```lua
local C = game.ServerStorage.KlinokDebug.Cmd
print(C:Invoke("floor 3"))
print(C:Invoke("give huntmaster_staff"))   -- pack_staff, moon_staff
print(C:Invoke("spawn guard 6"))
print(C:Invoke("nocd on"))
-- этаж 2: spore_staff, lotus_staff, gardener_crook; этаж 5: clock_staff, tome_staff, memory_staff
```
Что смотреть:
- **Ловля** — сеть ложится по зелёно-золотой зоне, копья бьют туда, где была красная метка.
- **Стая** — волки бегут и кружат, вой разгоняет соседей, укусы по очереди, общий прыжок.
- **Грибница** — грибы растут, облако держится 3 с, в конце хлопок.
- **Часы** — стрелка дважды обегает круг, потом «+N» над магом (сначала получи урон).
- **Финал серии** — третий выстрел посоха взрывается.
