# Озвучка «Клинок Памяти» — бриф

Один актёр, низкий, слегка хрипловатый голос, запись очень близко к микрофону,
лёгкая компрессия. Почти шёпот, без пафоса. Сила в паузах.

Файлы делать **по одной реплике** (под скрипт катсцены): Voice1…Voice5.
Каждый файл начинается сразу с голоса (без тишины в начале), скрипт сам
запускает его по таймкоду.

| Файл   | Таймкод | Текст | Подача |
|--------|---------|-------|--------|
| Voice1 | 0:04    | Мир помнит всё…  (пауза)  Даже то, что должен был забыть. | шёпот, очень близко |
| Voice2 | 0:11    | Первый Кузнец захотел сохранить каждую душу.  (пауза)  Каждое эхо. Каждую боль. | спокойно, чуть громче |
| Voice3 | 0:18    | Но память гниёт.  (пауза)  Воспоминания становятся чудовищами.  (пауза)  А мир… начинает забываться. | ровно, с нарастающей тяжестью |
| Voice4 | 0:26    | Ты — Пробуждённый.  (пауза)  У тебя нет имени. Нет прошлого.  (пауза)  Есть только пустой клинок…  и чужие воспоминания. | тише всего, с весом |
| Voice5 | 0:33.4  | Впитай. Или забудь. | чётко, финально, без вопросительной интонации |

Максимальная длина: Voice1 ≤ 6,5 с, Voice2 ≤ 6,5 с, Voice3 ≤ 7,5 с, Voice4 ≤ 6,5 с, Voice5 ≤ 3 с.

## Если голос генерируется ИИ (ElevenLabs)

- Модель: Multilingual v2, язык русский.
- Голос: низкий мужской, «narrator / deep / raspy».
- Stability 55–65 %, Similarity 75 %, Style 10–20 %, Speaker boost включён.
- Паузы задавать многоточиями и переносами строк, не словом «пауза».
- Каждую реплику генерировать отдельно, 3–4 дубля, выбрать лучший.
- После: лёгкий EQ (подрезать выше 10 кГц, добавить тепла на 120–200 Гц),
  компрессор 3:1, короткий реверб (зал, 15–20 %), нормализовать до −16 LUFS.

## Остальные звуки

Музыка, атмосфера и все эффекты теперь описаны в документе «Звуковая палитра»
(31 звук, у каждого тайм-код, роль в сцене и промпт для генератора).
Голос Voice1…Voice5 остаётся по этому брифу.

## Как загрузить в Roblox

Creator Hub → Assets → Audio → загрузить каждый файл (владелец — ваш аккаунт
или группа, звук должен быть доступен игре), скопировать ID в `CFG.SOUNDS`
в скрипте.
