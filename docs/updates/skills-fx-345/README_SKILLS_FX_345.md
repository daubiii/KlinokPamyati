# «Клинок Памяти» — эффектное обновление способностей оружия этажей 3–5 (воин)

Пакет того же уровня, что `klinok_skills_fx` для этажей 1–2 и мага: у каждой способности
и пассивки оружия этажей 3–5 теперь есть раскат удара, обломки, следы на земле, хвост
частиц на 2,5–4 с и отдельные звуки поверх прежних.

## Что было сломано (почему эффекты 3–5 «не играли» вообще)

Код эффектов 3–5 в проекте уже был, но три подключения потерялись при сборке:

1. **Обработчики не были зарегистрированы.** `AbilityFxHunt / Forge / Chronicle` нигде не
   добавлялись в `HANDLERS` контроллера `AbilityFx` — сервер слал фазы, клиент их молча
   пропускал. Исправлено в `Controllers/AbilityFx.lua`.
2. **Звуки оружия 3–5 не подмешивались.** `Config/SfxWeapons345` никто не подключал в
   `Config/Sfx`, поэтому 53 звука `hunt* / forge* / chron*` не находились. Добавлен блок
   подмешивания в `Sfx.lua` (уже существующие имена не перетираются).
3. **Шаблоны FX не строились.** `Shared/Fx/FxBuilder345.build()` ни разу не вызывался —
   пути `Hunt/… Forge/… Chron/…` были пустыми. Теперь вызов в `Bootstrap.server.lua`
   (после `FloorScenery.setupLighting`, в pcall).

Попутно:
- **Конфликт имён звука** `forgePour`: такое же имя у звука босса/врага этажа 4 в `Sfx.lua`.
  Звук «Разлива» переименован в `forgeSpillPour` (`SfxWeapons345.lua` + `AbilityFxForge.lua`).
- **Баг в `Lib/FxAfter.lua` → `Fx.seamPath`**: при `reveal > 0` замыкание брало внешнюю
  переменную `prev`, и все отрезки трещины рисовались от последней точки. Затрагивало и
  «Жатву» этажа 2. Исправлено (`local from = prev`).

## Как теперь выглядят способности

Новые модули — «продлённые» фазы, играют поверх базовых эффектов (как `AbilityFxPlus`
для этажей 1–2): `AbilityFxPlusHunt`, `AbilityFxPlusForge`, `AbilityFxPlusChronicle`
+ общий набор помощников `AbilityFxPlus345Kit`. Подключены в `AbilityFxPlus.lua`.

```
print(game.ServerStorage.KlinokDebug.Cmd:Invoke("give fang"))
print(game.ServerStorage.KlinokDebug.Cmd:Invoke("nocd on"))
print(game.ServerStorage.KlinokDebug.Cmd:Invoke("cam side"))

```

Короткие имена оружия:
- этаж 3: `cleaver broad bear fang trap royal falconer`
- этаж 4: `cast quench apprentice crucible searing anvil heart slag unfinished`
- этаж 5: `paper tome bookmark quill seal hourglass ink oblivion memory`

Звуки: `sfx` — список вариантов, `sfx fxForgeAnvilBoom 2` — прослушать и выбрать вариант 2.
Понравившийся номер вписать в `SfxSkills.picked` (по умолчанию у всех 1).

В Output при старте — строка `[AbilityFx] способности оружия: … охота, горн, летопись`,
и нет предупреждений `[AbilityFxPlus] …`.
