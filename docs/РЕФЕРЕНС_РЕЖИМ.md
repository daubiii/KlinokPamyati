## 1. ЧТО РЕЖИМ ДЕЛАЕТ ЛУЧШЕ НАС (главные выводы)

### A. Инвентарь оружия с ВИТРИНОЙ
Их инвентарь = сетка предметов слева + **крупная витрина выбранного оружия
справа** (оружие парит в воздухе с эффектом, статы панели рядом). У нас —
иконки 20×20 в сетке, никакого «вау».

→ **Применить в Клинке:** Книга героя / инвентарь — витрина выбранного
оружия в ViewportFrame (3D-модель парит с подсветкой редкости), статы справа.
Файл: `Windows/CharacterWindow.lua` (вкладка gear).

### B. Баннеры оружия / сетов (магазин)
У них оружие продаётся через **баннеры-карточки** с эффектным фоном (змея,
звезда, лимитированный таймер). У нас лавка — заглушка с текстом.

→ **Применить:** лавка (ShopWindow) — карточки оружия с фоном редкости
(по цвету сетки), кнопка «Купить», таймер ограниченных предложений.
Файл: `Windows/ShopWindow.lua`.

### C. Карта мира с выбором этажа
У них **карта мира** с цветными островами (каждый = этаж), клик → карточка
этажа: название, описание, сложность (звёзды), кнопка «Продолжить».
У нас врата — просто список этажей в окне.

→ **Применить:** Врата Печатей (GateWindow) — карта мира с островами-этажами,
карточка выбранного этажа с описанием и сложностью. Файл: `Windows/GateWindow.lua`.
Референсы: `world_map.jpg`, `world_map_floor1–5.jpg`.

### D. Дары/Повышение уровня — СВИТКИ-КАРТЫ
У них награды за этаж и level-up показываются как **3 свитка-карточки**
на тёмном фоне. У нас — те же 3 карточки, но без «предметности».

→ **Применить:** FloorBoonController — карточки в виде свитков (валы
сверху/снизу + пергамент между, как в выборe пути v4). Файл:
`Controllers/FloorBoonController.lua`. Референсы: `boon_cards_scrolls.jpg`,
`levelup_cards.jpg`.

### E. Восковые печати как элемент UI
Красные/лиловые **восковые печати** на каждом важном элементе (награды,
письма, баннеры). У нас — печати только в выборе пути v4.

→ **Применить:** награда квеста (доска), сундук дня, level-up — восковая
печать с оттиском поверх. Piece: `stampMark` (уже в PaperAtlas).

### F. Красный как акцент действия
У них **красный** — цвет действия (агрессия, урон, баннеры, печати).
У нас красный только в HP/уроне.

→ **Применить:** ВЫБРАТЬ/ЗАБРАТЬ кнопки — красные (воск), переплёты
книг — красные, активные вкладки — красные.

## 4. ПРОМТЫ ДЛЯ GPT (из референсов)

### Промт — карточка этажа (Врата Печатей)
```
Пиксель-арт карточка выбора этажа 512×380, вертикальная: тёмный фон
#14102A, сверху — пиксельный пейзаж этажа (миниатюра), под ним название
этажа золотым пиксельным шрифтом, 3 звезды сложности, кнопка «Продолжить»
золотая. Стиль: тёмное фэнтези Roblox low-poly, чёткие пиксели, БЕЗ текста
кроме названия.
```

### Промт — свиток-карточка даров
```
Три вертикальных пергаментных свитка 340×480 на тёмном фоне, каждый с
валами сверху и снизу (цилиндры), на пергаменте — пиксельная иконка дара
и название. Средний свиток чуть крупнее (выбран). Тёмное фэнтези,
пергамент #ECDEC0, чернила #423020, свечения редкости (золото/бирюза/
фиолет). БЕЗ текста кроме названий.
```

### Промт — восковая печать
```
Пиксель-арт восковая печать 128×128: круг тёмно-красного воска #8C2F2A
с рельефным оттиском меча в центре, неровные края, блеск на воске.
```

3. Промт из этого файла (§4) или АРТ_ЗАДАНИЕ §3.
