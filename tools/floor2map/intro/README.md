# Пакет «Клинок Памяти» — ролик за один прогон

## Файлы
- `BuildIntroStage.lua` — строит сцену из блоков (коридор, зал, кузня, 18 парящих клинков с силуэтами, пустой клинок, герой) и расставляет все точки камеры.
- `IntroCutscene.lua` — катсцена v2: полёт камеры, свет и пост-эффекты, частицы, звук, субтитры, заголовок.
- `Subtitles.srt` — английские субтитры (если делаете монтаж отдельно, поставьте `CFG.SUBTITLES = false`).
- `VOICE_BRIEF.md` — реплики, подача, список звуков.

## Порядок
1. Studio → View → Command Bar → вставить `BuildIntroStage.lua` → Enter. В Workspace появятся `IntroStage` и `IntroCam` (в Output строка «готово»).
2. `IntroCutscene.lua` → LocalScript в `StarterPlayer > StarterPlayerScripts`.
3. Загрузить звуки, вставить ID в `CFG.SOUNDS` (без них ролик идёт немой).
4. Включить запись экрана (OBS, 1920×1080, 60 fps), нажать Play (F5). Ролик стартует через 2 сек и идёт ровно 38,5 сек, в конце чёрный экран.
5. Графика Studio: Settings → Rendering → Graphics Quality на максимум.
6. Для игроков: `CFG.RECORD_MODE = false`, и в игре ролик запускается сам при входе.

## Эффекты (подогнаны под ваши референс-скрины)
Ручки в `CFG.FX` в начале катсцены: `ParticleDensity` (количество частиц), `BloomIntensity/Size/Threshold` (свечение), `Vignette`, `Saturation`, `Contrast`.
- Палитра: сине-фиолетовая ночь, голубой `#6FE3FF` с белым «горячим» ядром, тёплые оранжевые угольки только у горна.
- Частицы только квадратные: искры в воздухе, вихрь по спирали при поглощении, россыпь искр с наковальни (оранжевые + голубые), подъём кубиков вдоль светового столба, рассыпание силуэта.
- Свет: кристаллы с белым ядром, столб с площадкой в конце коридора, пиксельное пламя горна.

## Если что-то выглядит не так
- Сцена слишком тёмная/светлая: `setupLook()` в катсцене (Ambient, ExposureCompensation, Bloom).
- Камера видит не то: двигайте прозрачные Part-ы в `IntroCam` (Shot1…Shot6B); камера смотрит в сторону передней грани.
- Нужны ваши модели вместо сгенерированных: удалите/замените детали в `IntroStage`; имена `Blades`, `EmptyBlade`, `Hero` скрипт использует для анимации.
