# Оружие этажа 1: модели, статы, способности — пакет для агента

Сделано 24.10.2026, всё согласовано с Артёмом:
- модели (лист `preview/weapons_floor1_v1.png`);
- размеры в руке: мечи около 4,9–5,3 стада, молоты около 5,3, Ключ около 7;
- статы по предметам;
- способности «Вихрь-воронка», «Разлом», «Отпереть» и пассивка «Скважина».

Пакет из трёх частей:
- **`src/`** — код. Накладывается поверх `src/` проекта с заменой файлов, Rojo синхронизирует его сам.
- **`map/`** — меши. Импортирует **Артём руками** в Studio (шаги ниже).
- **`tools/weapons/`** — исходники генератора (Python + Blender). Положить в `tools/weapons/` репозитория.

Пока меши не залиты, игра работает как раньше: оружие строится из старых вокселей. Код способностей от мешей не зависит.

### Числа

Процент способностей — от урона оружия: урон воина × `Weapons.Items[id].damage` × множитель способности за ★ эха × бонус легендарки.

| Способность | Что делает | Перезарядка |
|---|---|---|
| **Вихрь-воронка** | Каст 1 с. Тики на 0,2 / 0,5 / 0,8 с: по 70% в радиусе 5,5 и стягивание до 1,6 стада. Волна на 1,0 с: 90% в радиусе 7 и отброс на 3 стада | 13 с |
| **Разлом** | Прыжок до 6 стадов за 0,42 с; сервер обрезает его по стене и пропасти. Удар 200% в радиусе 5, оглушение 1 с, −5 брони на 6 с. 3 трещины веером ±40° до 10 стадов, обрезаются стеной. Через 0,6 с — 120% по полосе шириной 2,6, каждый враг получает урон один раз | 15 с |
| **Отпереть** | Каст 0,55 с. Замок радиусом 8: враги скованы на 2,5 с (боссы на 1 с) и получают +25% урона. Через 2,5 с — взрыв 240% в радиусе 8 и отброс на 3,5 стада | 18 с, с −8% легендарки 16,6 с |
| **Скважина** (пассивка Ключа) | Финал серии ставит метку, метка живёт 8 с. На 3-й метке через 0,15 с — удар ключом на 100% удара (без финала, крита и контратаки) | — |

## 2. Меши (`map/`) — делает Артём в Studio

Скрипты запускает **человек** в **Command Bar**, в режиме **Edit**, не во время Play.

1. **Импорт.** File → Import 3D → `map/weapons_floor1.glb`, настройки не менять.
   - В Workspace появится модель `weapons_floor1` с 14 MeshPart:
     - `W_<оружие>` — 8 штук, с палитрой;
     - `G1_` / `G2_<оружие>` — свечение эпиков и легендарки.
   - Палитра встроена в glb, импорт загрузит её сам.
   - OBJ не годится: импорт сливает его в одну деталь.
2. **Сборка.** Вставить весь текст `map/AssembleWeapons.lua` в Command Bar и нажать Enter.
   - В Output должно появиться: `[AssembleWeapons] готово: 14 из 14 MeshPart в ReplicatedStorage.WeaponMeshes, не найдено 0`.
3. **Проверка на глаз.** Вставить `map/PreviewWeapons.lua` в Command Bar.
   - Перед камерой встанут 8 моделей. В Output у каждой должно быть «меш».
   - **Если свечение съехало** с клинка или бойка, импорт развернул меши. Тогда у `ReplicatedStorage.WeaponMeshes` поставить атрибут `ImportYaw = 180` и снова запустить `PreviewWeapons` дважды: первый раз убирает витрину, второй ставит.
   - Витрину убрать вторым запуском скрипта.
4. Сохранить место (Ctrl+S). `WeaponMeshes` живёт только в файле места (`$ignoreUnknownInstances`).

Там же лежат:
- `weapons_floor1.blend` — модели в Blender для правок руками;
- `weapons_floor1.obj/.mtl` и `weapons_palette.png` — исходник glb.

## 3. Проверка в Play

Выдать себе оружие: Command Bar в Play, контекст **сервера**.

```lua
print(game.ServerStorage.KlinokDebug.GiveWeapon:Invoke(nil, "vortex_blade"))
-- "shattered_hammer", "gatekeeper_key", "rusty_sword", "iron_falchion",
-- "forge_hammer", "guard_blade", "guard_hammer"
```

Чек-лист:

- [ ] В руке новая модель. Иконка в окне снаряжения — тоже новая модель.
- [ ] HUD: у эпиков и легендарки на слоте «1» иконки `whirl` / `split` / `key`; у обычного и редкого слот закрыт.
- [ ] **Вихрь-воронка** в толпе:
  - [ ] два оборота корпуса;
  - [ ] спираль кубиков сходится к герою;
  - [ ] 3 тика урона, враги подтягиваются;
  - [ ] в конце волна отбрасывает;
  - [ ] удар ЛКМ во время кружения не начинается;
  - [ ] перезарядка 13 с.
- [ ] **Разлом**:
  - [ ] прыжок вперёд около 6 стадов;
  - [ ] перед стеной прыжок короче;
  - [ ] у обрыва — на месте;
  - [ ] удар оглушает, значок «Б» (снятая броня);
  - [ ] три трещины растут и пульсируют;
  - [ ] через 0,6 с — каменные столбы и урон стоящим на трещине;
  - [ ] на пандусе не бьёт врагов этажом ниже.
- [ ] **Отпереть**:
  - [ ] ключ в землю, луч;
  - [ ] золотое кольцо радиусом 8;
  - [ ] цепи и замочки на врагах, враги стоят 2,5 с;
  - [ ] урон по ним больше на 25%;
  - [ ] через 2,5 с — вспышка, разлёт кубиков, урон и отброс;
  - [ ] Привратник и мини-боссы скованы только на 1 с.
- [ ] **Скважина**: финал серии по одному врагу ×3 — над ним 1…3 золотых кубика, на третьем падает ключ из света и бьёт (крит-цифра).
- [ ] Молоты: финал серии чуть сдвигает обычных врагов, Привратника — нет.
- [ ] Старое сохранение со «Вихрем клинка» на Ключе: после входа способность «Отпереть».
- [ ] Второй игрок (Test → 2 Players) видит эффекты чужих способностей.
- [ ] В Output нет ошибок `[AbilityFx]` и `[VoxelWeaponBuilder]`.

## 4. Генератор (`tools/weapons/`) — если понадобится перегенерировать

```
pip install bpy==5.2.* numpy pillow --break-system-packages
python3 export_weapons.py <папка выхода>   # obj/mtl/png/glb/blend + WeaponMeshData.lua
python3 render_weapons.py out.png all 48 2400   # лист превью
python3 render_one.py gatekeeper_key out.png 640   # одно оружие, прозрачный фон
```

- Формы — `weapons3d.py`: воксель 0,125 стада, X поперёк клинка, Y вдоль, хват в 0.

## Оружие этажа 2

Восемь видов оружия, их статы, лут, три способности и пассивка «Цветение»
добавлены в `src/`. Сундуки используют пул и веса редкостей этажа игрока;
для этажа 2 это 220 золота и 3–5 единиц болотного тростника.

Меши и инструменты лежат в `tools/weapons/floor2-assets/` и
`tools/weapons/`; эффекты — в `tools/fx/BuildFxGarden.lua`.

### Установка мешей и эффектов в Studio

1. Выполнить `node tools/sync.js`, чтобы отправить новые модули из `src/` в Studio.
2. В Studio, в режиме Edit, запустить `tools/fx/BuildFxGarden.lua` через Command
   Bar. Если папки `ReplicatedStorage.FX` ещё нет, сначала запустить `BuildFx.lua`.
3. Импортировать через **File → Import 3D** файл
   `tools/weapons/floor2-assets/weapons_floor2.glb` без изменения настроек.
4. Запустить `tools/weapons/AssembleWeaponsFloor2.lua` через Command Bar. В
   Output ожидается 14 MeshPart и 0 пропусков. Затем выполнить Ctrl+S.
5. Для осмотра запустить `tools/weapons/PreviewWeaponsFloor2.lua`; повторный
   запуск убирает витрину. В Play проверить выдачу через `give reaper_blade`,
   `give tidal_hammer` или `give gardener_shears`.

Текстуры листа, лепестка и капли в `tools/fx/textures_garden/` необязательны:
эффекты работают и без их загрузки в Roblox. Для использования загрузить PNG в
Creator Hub, указать asset ID в `NEW` в `BuildFxGarden.lua` и запустить скрипт
с `REBUILD = true`, затем вернуть `false`.
