# Карта этажа 1 v2 (Floor1Map): сборка и правки

Пакет `KlinokFloor1v2/map` → Studio. Отличия от README пакета — ниже.

## Видимые меши: только через glb

Import 3D сливает OBJ в одну MeshPart, а Roblox режет меш до 20 000 треугольников:
двор, башня, зал, босс теряли половину стен и пола (дыры). Поэтому:

```
python tools/floor1map/floor_obj_to_glb.py <пакет>/map
```

→ `out/floor1v2_a.glb`, `_b`, `_c` (узел = объект OBJ, все < 20 000). Там же вырезаются
проёмы, которых нет в мешах пакета (`CUTS`: вход в Зал лебёдки с моста).

1. Import 3D → каждый из трёх glb, настройки не менять. Модели `floor1v2_a/b/c` остаются в Workspace.
2. `node C:\Users\artem\.dsh-roblox\s.js exec tools/floor1map/AssembleFloor1.lua Edit`
   → «388 из 388». Старые слитые меши из `Visual` удаляются сами.
3. Ctrl+S.

## Коллизии: fix_collisions.lua

```
sh tools/floor1map/run_fix.sh
```

Склеивает `fixlib.lua` + `bounds_data.lua` + `fix_collisions.lua` и выполняет в Studio.
Шаги одноразовые (атрибут `Floor1Map.CollisionFixes`), `bounds` пересобирается каждый раз.

| Шаг | Что было |
|---|---|
| shiftY | Insert from File поднял Floor1Map на +2: невидимый пол висел над видимым |
| towerStairs | лестница с вершины башни на мост к залу — сплошной блок 6 стад |
| towerSlab | квадратная плита вершины углами нависала над 3-м витком пандуса |
| towerParapet | парапет вершины 3.2 стада сплошным кольцом, без входа с пандуса |
| hallDoor | стена Зала лебёдки без проёма под `Gate_HallIn` |
| towerBarricades | баррикады перекрывали пандус целиком — сдвинуты к внутреннему краю (точки `BARRICADE_n` тоже) |
| chapelDais | помост у алтаря часовни без коллизии |
| bounds | невидимые стены там, где с пола можно выйти на тёмную плиту за стенами |

`bounds_data.lua` генерируется аудитом проходимости (заливка по коллизиям от старта,
«снаружи» = плита на y −0.12 в мешах, двери между зонами — кратчайшие пути по плите).
Пересобирать при изменении коллизий.
